# BOSS

BOSS is a GitHub bounty app for open-source software. It lets maintainers, users, and sponsors attach monetary rewards to GitHub issues so contributors can earn by completing scoped work through the repository's normal pull request process.

The app is relevant to the Gitcoin Funding Directory because it provides issue-level funding for open-source maintenance. It is best suited to concrete work such as bug fixes, documentation updates, tests, integration tasks, and small features where completion can be reviewed directly in GitHub.

## What This App Does

BOSS connects GitHub issue work with bounty payments.

In practice, it enables:

* **Projects** to install a GitHub App and make bounty status visible on issues
* **Funders** to reward specific bugs, features, or maintenance tasks
* **Contributors** to discover funded GitHub issues and earn from accepted work
* **Maintainers** to keep review and merge decisions inside their existing GitHub workflow
* **Communities** to financially prioritize work without creating a full grants program

## Features

### GitHub-Native Bounties

BOSS works through GitHub issues and issue comments. This keeps bounty creation, contributor discussion, and implementation close to the existing repository workflow instead of forcing projects into a separate task tracker.

### Issue-Level Incentives

The bounty model gives funders a way to signal demand for a specific issue. This can help projects attract contributors to tasks that are valuable but not large enough for a formal grant.

### Open-Source Maintenance Support

Because BOSS is focused on small, scoped issues, it can support recurring open-source maintenance: bug fixes, documentation, tests, dependency updates, and other reviewable work.

## Use Cases

**Contributor Discovery**

Projects can use bounties to make good first issues or maintenance tasks more attractive to external contributors.

**Community-Prioritized Work**

Users can fund the bugs or features that matter to them and give maintainers a clearer signal about where external demand exists.

**Lightweight Public Goods Funding**

BOSS gives open-source communities a simpler mechanism than grant rounds when the desired outcome is specific, small, and easy to verify through GitHub.
