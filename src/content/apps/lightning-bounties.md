# Lightning Bounties

Lightning Bounties is a GitHub-native bounty platform for open-source work. It lets funders attach Bitcoin rewards to GitHub issues, contributors solve those issues through normal pull requests, and accepted work receive payment through the Bitcoin Lightning Network.

The platform is useful for work that is smaller and more concrete than a formal grant: bug fixes, documentation updates, integration tasks, design improvements, and other issue-based contributions. By anchoring rewards to GitHub issues, Lightning Bounties keeps contributor discovery, review, and completion close to the development workflow maintainers already use.

## What This App Does

Lightning Bounties provides a task-based funding rail for GitHub issues.

In practice, it enables:

* **Funders** to create or fund bounties by attaching rewards to GitHub issues
* **Contributors** to browse available bounties and pick issues they can solve
* **Maintainers** to keep review and merge decisions inside the normal pull request process
* **Communities** to add funding to specific issues they want prioritized
* **Open-source projects** to reward small, scoped work without launching a full grants program

## Features

### GitHub Issue-Based Rewards

Lightning Bounties is built around GitHub issues and pull requests. A funder can point to an issue, attach a reward, and make the bounty visible to potential contributors. Contributors then use the repository's existing contribution process to implement the requested change.

### Lightning Payments

Rewards are paid through Bitcoin Lightning, which can make small international payouts faster and cheaper than traditional payment rails. This is especially relevant for contributors who are outside the banking regions normally served by standard payroll or invoice systems.

### Crowdfunded Bounties

The platform supports multiple people adding funds to a bounty. This lets communities signal demand for specific fixes or improvements without requiring a single maintainer or sponsor to fund the whole amount.

## Use Cases

**Small Open-Source Maintenance Tasks**

Projects can use Lightning Bounties for issues that are too small for a grant but still valuable enough to fund: dependency updates, documentation fixes, tests, bug fixes, and UI improvements.

**Community-Prioritized Issues**

Users and supporters can fund the issues they care about. This helps maintainers understand which work has external demand and gives contributors a clear economic signal.

**Global Contributor Payouts**

Lightning-based rewards can be useful when contributors are distributed across regions and small cross-border payments would otherwise be inefficient.
