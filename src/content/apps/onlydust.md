# OnlyDust

OnlyDust is an open-source contribution platform for contributors, maintainers, and ecosystems. It helps contributors discover projects and issues, helps maintainers manage contribution activity, and supports rewards or program-based funding for eligible open-source work.

The platform is relevant to the Gitcoin Funding Directory because it connects open-source contribution activity with funding, contributor onboarding, project visibility, and ecosystem programs. It is broader than a simple bounty board, but it serves a similar public-goods role by helping contributors find funded or supported work.

## What This App Does

OnlyDust supports open-source contribution discovery, tracking, and rewards.

In practice, it enables:

* **Contributors** to discover projects and contribution opportunities
* **Maintainers** to make projects visible and track contributor activity
* **Ecosystems** to run contribution programs, open-source weeks, and funding initiatives
* **Projects** to connect GitHub activity with contributor profiles and reward flows
* **Communities** to support contributors through structured programs instead of ad hoc coordination

## Features

### Contributor Discovery

OnlyDust gives contributors a way to find open-source projects, issues, and programs that match their interests or skills. This helps reduce the search cost of finding funded or supported work.

### Maintainer and Project Dashboards

Maintainers can use OnlyDust to make projects visible, track contribution activity, and coordinate external contributors across GitHub-linked workflows.

### Reward and Program Flows

OnlyDust supports rewards, fellowships, open-source weeks, and ecosystem-backed programs where contributors may receive funding or other support based on eligible activity.

## Use Cases

**Ecosystem Contributor Programs**

Ecosystems can use OnlyDust to direct attention and funding toward projects that need contributors.

**Open-Source Contributor Onboarding**

Maintainers can make project opportunities more discoverable and give contributors clearer paths into useful work.

**Contribution Tracking and Recognition**

OnlyDust helps connect GitHub contribution activity to contributor profiles, making work easier to review, recognize, and potentially reward.
