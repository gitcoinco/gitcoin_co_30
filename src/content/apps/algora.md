# Algora

Algora is a GitHub-integrated platform for open-source bounties, tips, contracts, and hiring. Teams can fund GitHub issues, contributors can submit pull requests, and rewards are paid when work is completed and accepted.

The platform is relevant to the Gitcoin Funding Directory because it provides an outcome-based funding mechanism for open-source software work. It is especially useful for scoped issues where a sponsor wants to pay for a merged pull request rather than run a broader grant process.

## What This App Does

Algora connects GitHub contribution activity with bounty and contract payments.

In practice, it enables:

* **Sponsors** to create USD-denominated rewards on GitHub issues
* **Contributors** to find open bounties and submit pull requests
* **Maintainers** to approve work through their normal GitHub review process
* **Teams** to trial contributors through paid open-source tasks
* **Communities** to tip or reward contributors for useful work

## Features

### GitHub Issue Bounties

Algora lets projects add rewards to GitHub issues. The bounty remains tied to the issue and can be claimed through a pull request when the contribution is merged or otherwise accepted.

### Bounty Boards

Project pages show open bounties, completed bounties, total awarded amounts, solvers, and contributor activity. This makes funding history visible to both contributors and maintainers.

### Payments and Compliance

Algora handles payout administration for bounty and contract workflows. This reduces operational overhead for teams that want to reward external contributors without building their own payment process.

## Use Cases

**Open-Source Maintenance**

Teams can fund bug fixes, documentation, tests, integrations, and scoped features without creating a standing grants program.

**Contributor Trials**

Companies can use paid open-source tasks to evaluate real contributors before hiring or contracting more deeply.

**Public Contributor Recognition**

Visible bounty pages and solver history help contributors build a public record of paid open-source work.
