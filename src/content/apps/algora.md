## Description

Algora is an open-source bounty platform that lets maintainers and sponsors add monetary rewards to GitHub issues. The public bounty pages show open and completed bounties, total awarded amounts, solvers, and project-level bounty history.

Algora is relevant to the Gitcoin Funding Directory because it provides a lightweight mechanism for outcome-based funding of open-source work. A maintainer or sponsor can fund an issue, contributors can solve it through normal GitHub pull requests, and rewards can be paid after work is merged.

Typical workflow:

1. A project or sponsor chooses a GitHub issue.
2. They fund the issue with a bounty amount.
3. Contributors review open bounties and submit pull requests.
4. The project reviews and merges accepted work.
5. Algora handles contributor payout and related payment administration.

### Strengths

- Direct GitHub issue workflow with visible bounty pages.
- Public records of open and completed bounties improve transparency.
- Supports small maintenance tasks as well as larger implementation work.
- Can help maintainers attract contributors without creating a grants program.
- Includes tools for tips and project-level contributor reward history.

### Limitations

- Contributors still need accepted pull requests; funding alone does not guarantee merge.
- Payment and compliance details are handled by Algora and may vary by region.
- The platform is task-oriented, so it is less suitable for broad, exploratory grants.
- Projects need sufficiently clear issues for bounty contributors to work efficiently.
